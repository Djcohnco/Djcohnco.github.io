# Internal Documentation

This site documents how my systems are built, deployed, and operated.

## What’s here
- **CI/CD**: pipelines, branching, release flow
- **Deploy**: environments, infra, containers, rollback
- **Runbooks**: operational procedures + incidents
- **Standards**: conventions, logging, secrets handling

## Golden rules
- No secrets in docs.
- If it isn’t documented, it doesn’t exist.
- Every runbook ends with “How to verify success” + “How to rollback”.
